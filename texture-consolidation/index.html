Project page for "Texture Consolidation of Generated Multi-View Renderings"

Texture Consolidation of Generated Multi-View Renderings

Hongyi Liu1 Yifan Wang2 Vladimir G. Kim3 Misha Kazhdan1
1Johns Hopkins University 2Adobe Research 3Adobe Firefly Foundry
arXiv

Abstract

We present a system for consolidating a sparse set of multi-view renderings into a single coherent texture image, providing a framework for integrating generative models for image generation within the geometry-processing pipeline. Given a texture-atlased triangle mesh and a set of renderings with associated camera parameters, we generate the texture image by: (1) back-projecting the renderings onto the mesh to obtain texture images with normalized colors and confidences; (2) solving for flow-fields on the mesh that align the colors to each other, taking into account the associated confidences; and (3) fusing the registered colors into a single texture image using gradient-domain stitching, again incorporating confidences. Our approach complements existing techniques for multi-view image generation, leveraging mesh-based optical flow and texture-space stitching. In doing so it addresses the challenge that while modern image generation pipelines generate highly convincing renderings, they struggle to produce renderings that are consistent across views.

Results

Front views of textured mesh output using nine generated renderings. The front view shown is not one of the nine inputs. Fusing misaligned renderings directly leaves ghosting and blur, while selecting one view per patch, as MVS-tex does, stays sharp inside each patch but leaves seams where patches meet. Methods designed for dense RGB-D captures, such as ColorMap and AdvIA, degrade on a sparse set of inputs. Our method registers the renderings on the surface before fusing them, producing a seamless, ghost-free texture.
